# Exercise answers

Worked answers for every lesson's exercises — attempt them first; the
learning is in the attempt, and several exercises are designed to make
you hit an instructive wall before the answer names it.

- One `NN-answers.md` per lesson (lessons 1–16 and 18). Lesson 0 has
  no exercises; lessons 17 and 19 ask open-ended questions with no
  single answer to write down.
- Where an answer is a runnable program it ships alongside as
  `NN-answers.dl` (or a `.dfl` theory, or a `.py` script) — run the commands shown in each
  file.
- **Everything here is verified**: `ExerciseTests` in `tests.py`
  executes every runnable answer and checks the claimed results, so the
  answers cannot rot.
